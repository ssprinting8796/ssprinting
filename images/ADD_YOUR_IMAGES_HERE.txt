SS PRINTING WEBSITE - LOCAL IMAGE SETUP

FILES
- index.html       Main website page
- css/style.css    Website design
- js/script.js     Website functionality
- images/          Put your own photos/design samples here

IMPORTANT
No external website image links are used in this project.
The gallery expects these local image files:

images/visiting/visiting-card-1.jpg
images/visiting/visiting-card-2.jpg
images/billbook/billbook-1.jpg
images/billbook/billbook-2.jpg
images/sticker/sticker-1.jpg
images/sticker/sticker-2.jpg
images/banner/banner-1.jpg
images/banner/banner-2.jpg
images/stationery/stationery-1.jpg
images/gifts/gifts-1.jpg
images/gifts/gifts-2.jpg
images/bags/bags-1.jpg
images/bottles/bottles-1.jpg
images/other/other-1.jpg

Create the category folders shown above inside images, then copy your own photos
into them using the exact filenames. You can use JPG, PNG or WebP, but if you
use another extension, update that filename in js/script.js too.

HOW TO OPEN
1. Extract the ZIP file.
2. Keep index.html, css, js and images together in the same main folder.
3. Double-click index.html to open the website in your browser.

You can change the sample titles and image filenames in js/script.js.
